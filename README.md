# CORTEX — An Expedition Inside Your Mind

A single-player 3D educational game that runs entirely in the browser.

**Play:** https://aiongio.github.io/cortex-expedition/

Walk a calm "mind museum", enter ten environments — memory, dreams, anxiety, mindfulness,
perspective, focus, the teenage brain, personality, creativity and beliefs — solve a hands-on
challenge in each, then reflect and keep local field notes.

- One file: `index.html` contains the whole game (HTML, CSS, JavaScript, Three.js, procedural
  models, textures and sound). No accounts, no backend, no analytics, no network requests after load.
- Controls: WASD / arrow keys to move, drag to look, wheel to zoom, E or click to interact,
  M map, J journal, Esc pause. Touch: left joystick, right-side drag, Interact button.
  An assisted mode (Settings) lists every interaction as a button.
- Progress and notes stay in your browser's local storage for this website only. Use
  Journal → Data to export or import a save file.

CORTEX is an educational game. It is not a diagnosis, treatment, personality test, intelligence
test or validated cognitive assessment. Educational content adapts a ten-topic guide supplied by
the project owner, inspired by *The Mind, Explained* (Seasons 1–2). Independent project — not
affiliated with, sponsored by, or endorsed by Netflix or Vox.
